# Prompt formula

```
[Style/genre + look] [Duration, aspect]
[timecode] Shot N: <shot size>, <ONE camera move>, <subject + action>, <environment/light>.
  Dialogue: (speaker, language) "line"        <- typed, in quotes
  SFX: ...
BGM: ...
Continuity: same face/outfit as @image1; no text overlays, no watermark.
```

Order inside a shot: **camera -> subject -> action -> setting -> light -> sound**.
Keep 15s clips to 3-5 shots; each shot >= 2s. Describe what is seen, not feelings.
Reference roles: `@image` identity/product/style frame, `@video` motion or camera to copy
("follow all camera movement from @video1"), `@audio` rhythm/voice timbre (keep influence ~70-80%).
Limits to respect: <=15s output, roughly <=9 images, <=3 videos, <=3 audio, <=12 files total.
